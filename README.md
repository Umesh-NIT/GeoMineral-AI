# GeoMineral AI

## AI-Powered Mineral Prospectivity Mapping

GeoMineral AI is a geospatial artificial intelligence platform designed to identify areas that may be prospective for lithium pegmatites and Rare Earth Elements (REE).

The project integrates:

- GSI Bhukosh / NGDR occurrence data
- Sentinel-2 spectral information
- Geological data
- Aeromagnetic data
- Geochemical data

The system processes these datasets into spatial features and uses machine learning to generate mineral prospectivity scores.
